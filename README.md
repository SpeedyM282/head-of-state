# Президент — сатирический политический симулятор

Мобильная игра в духе Plague Inc.: игрок правит вымышленной страной, балансируя между народом, элитами и казной. Вектор правления (демократия ↔ тоталитаризм) складывается из решений игрока и меняет правила игры.

Документы: [GDD.md](./GDD.md) · [ARCHITECTURE.md](./ARCHITECTURE.md) · [CLAUDE.md](./CLAUDE.md) (правила для Claude Code)

## Стек

React 19 · TypeScript (strict) · Vite · Zustand · Tailwind v4 · Vitest · Capacitor 8 (Android)

## Команды

```bash
pnpm install       # зависимости (менеджер пакетов — pnpm, см. packageManager в package.json)
pnpm dev           # дев-сервер
pnpm test          # тесты, включая автоигрока (смотри статистику в выводе)
pnpm typecheck     # проверка типов
pnpm build         # прод-сборка
pnpm cap:sync      # прод-сборка + копирование в android/ (Capacitor)
pnpm exec cap open android   # открыть нативный проект в Android Studio (нужны JDK + Android SDK)
```
